# Changelog

## 2.1.0
- First public release as **The Island** (plugin slug `SilenceTouch-TheIsland`).
- New expander **The Island Room**: room width / depth / height, units, ratio entry, FIT / ROUND orbit.
- Output layouts 4.0, 5.1, 7.1, 7.1.4; unused outputs and speakers are dimmed.
- Four panel themes: Sky, Mist, Sand, Dark, plus Auto.
