# The Island — a spatial panner for multi-channel mixing（VCV Rack 2）

English: [README.md](README.md)

深觸 Silence Touch 出品。12 軌立體聲輸入，在一個 3D 立方體裡擺放聲源，輸出最多 12 聲道（4.0／5.1／7.1／7.1.4），
**聲道順序為 SMPTE 標準**，可直接接到多聲道音訊介面或播放系統的通道 1–12。

外掛包含兩顆模組：
- **The Island**（模組代號 `TheIsland`）：12 軌空間聲像主模組。
- **The Island Room**（模組代號 `TheIslandRoom`）：房間比例擴充模組，緊貼在主模組旁邊使用。

外掛名稱是 **Silence Touch**、外掛代號是 `SilenceTouch`（代表深觸品牌，之後的新模組也會放在同一個外掛裡）。
舊版（外掛代號 `SilenceTouchSpatial` 或 `SilenceTouch-TheIsland`、模組代號 `Atmos714`）的 patch 請用
`tools/convert_patches.py` 轉換，見下方「從舊版升級」。

## 功能
- **12 軌立體聲輸入**：每軌的 **L / R 兩個輸入並排在同一排**，右邊緊接著該軌的 **LVL** 音量旋鈕；各軌有 **X（左右）/ Y（後前）/ Z（下上）** 三軸旋鈕與各自的 CV 輸入（雙極性，0 V = 停在旋鈕位置，±5 V = ±1；右鍵 CV range 可改成 ±10 V）。Y 旋鈕預設在前牆（+1），負電壓讓聲音往後走。
  - **WIDTH**：L 與 R 在 X 方向各自離中心點多遠。L 放在中心點左邊、R 放在右邊，各自獨立空間化，所以立體聲場可以自由擺放、拉寬、收窄，也會跟著整體旋轉。WIDTH = 0 就是單聲道。
  - 只接 L（或只接 R）時，當成單聲道放在中心點。
  - LVL、LFE send 在 L/R 兩個訊號上共用；LFE send 是 L+R 的平均。
- **立方體顯示**：房間以立方體呈現。立體聲軌道畫成一條**膠囊**（兩端就是 L、R 的位置），單聲道畫成圓點，編號在中間；
  顯示的是含 CV、繞場、旋轉之後的實際位置。ISO 視角在地板上有淡淡的影子，幫助判斷水平位置與高度。
  **沒接線的軌道不顯示**。喇叭以暗色小方塊與標籤標示（藍色 = 天花板喇叭）。
  **點一下立方體切換視角**：ISO（立體）→ TOP（俯視）→ FRONT（正視）→ SIDE（側視）；也可從右鍵選單選擇。
- **繞場（ORB）**：每軌最右邊三個元件。
  - **ORB 按鈕**：這一軌的聲音從目前的位置出發，以房間中心為圓心繞場，開始與結束時半徑會平滑過渡，不會跳。
    - 「繞一圈」模式（預設）：按一下繞一圈，繞完剛好回到原位；繞的途中再按不會重來。
    - 「持續繞」模式：按一下開始一直繞；再按一下會把目前這一圈繞完，回到原位後停下。
  - **DIA**：繞場的直徑，100% 時圓圈碰到四面牆（預設 90%）。
  - **SP（SPLIT）按鈕**：L、R 從立體聲中心往兩側分開，L 往左、R 往右鏡像繞圈（速度 = SPD；ORB 沒開時可由 LFO 孔控制角度）。
  - **LFO 插孔**：可以一直接著，只有按下 ORB 開啟繞場時才由 LFO 控制繞的角度（再按一下關閉、滑回原位），±5 V = ±180°。接**鋸齒波** LFO 會一直朝同一方向轉圈，
    LFO 的速度就是轉圈速度；接**正弦波**則是左右來回擺動。
  - **SPD**：這一軌的繞場速度，往右轉越快，最左 60 秒一圈、最右 1 秒一圈（預設約 7.7 秒）。
  - **ORB RATE**（右下）：全部軌道的速度倍率 0.25×～4×（預設 1×），現場一顆旋鈕整體加速或放慢。
  - 右鍵選單 **Orbit**：可以「All tracks」一次設定全部軌道，或「Track 1～12」各自設定：
    **Mode**（One turn 繞一圈／Loop 持續繞）、**Direction**（Left 往左逆時針／Right 往右順時針）、**Axis**（見下）。
  - 繞場軸：
    **Z** = 水平轉圈（預設，高度不變）、**X** = 垂直轉圈 前 → 天花板 → 後 → 地板（左右不變）、
    **Y** = 垂直轉圈 右 → 天花板 → 左 → 地板（前後不變）。
  - 右鍵選單 **Rotate axis** 同樣可以選 ROTATE 旋鈕的旋轉軸。
  - 繞場時立方體上會畫出那一軌的繞場軌跡（淡色圓圈），立體聲的 L/R 方向也會跟著轉。
  - 繞場之後還會再套用整體的 ROTATE。
- **Mute／Solo**：每軌最右邊的 **M**（靜音，亮紅燈）與 **S**（獨奏，亮黃燈）。只要有任何一軌開 S，就只聽得到有開 S 的軌道；
  開了 M 的軌道一定沒聲音（同時開 M 和 S 以 M 為準）。切換時約 5 ms 淡入淡出不會爆音；被關掉的軌道在立方體上變暗。
  右鍵選單有 **Unmute all tracks**、**Unsolo all tracks** 可一次取消。每次打開 patch 時 M、S 都會回到關閉；Randomize 不會動到 M、S、ORB 按鈕。
- **輸出配置**（右鍵選單 Output layout）：
  - **4 聲道**：L R Lrs Rrs（只有前左右與後左右）
  - **5.1**：L R C LFE Ls Rs（輸出 1～6）
  - **8 聲道**：L R C LFE Ls Rs Lrs Rrs（7.1）
  - **12 聲道**：完整 7.1.4（預設）
  沒有接的喇叭不參與聲像計算，聲音只會分配給有接的喇叭；立方體上沒接的喇叭畫得很淡，輸出區沒用到的輸出孔也會變淡。
  **12CH POLY 輸出的聲道數會跟著配置變成 4 / 6 / 8 / 12**，順序維持 SMPTE 相對順序
  （4 聲道時：1 L、2 R、3 Lrs、4 Rrs）。面板下方 12 個單聲道輸出固定在 SMPTE 位置（1 L … 12 Rtr），沒用到的為靜音。
- **ROTATE**：整體水平旋轉所有聲源（-180°～180°），CV 輸入 ±5 V = ±180°，接 LFO 即可繞場旋轉
- **FOCUS**：定位集中度；**BLUR**：空間模糊半徑；**MASTER**：總音量
- 每軌 **LVL** 與 **LFE** 送出（LFE 為 120 Hz 低通，12 dB/oct；4 聲道配置沒有 LFE 輸出）
- **電平指示（防爆音）**：VCV 的 Audio 模組以 **10 V = 0 dBFS**（數位滿刻度），超過就會爆音。
  - **每個輸出孔右側一顆 LED**：綠 = 有訊號、黃 = 偏熱（5 V 以上，約 −6 dBFS）、**紅 = 爆音（10 V 以上）**。
    紅燈會亮住 1.5 秒，一瞬間的爆音也看得到。
  - **每軌編號旁一顆 LED**：同樣的顏色規則，量的是該軌套用 LVL 之後的輸入（L/R 取較大者），用來找出是哪一軌太大聲。
  - **立方體**：該軌爆音時，它的點外面會出現紅圈；左下角會列出正在爆音的輸出聲道（例如 `CLIP C Ls`）。
  - 處理方式：先降那一軌的 LVL，或降 MASTER。多軌疊在同一個方向時，那個方向的喇叭最容易爆。
- **安全限幅器**（右鍵選單 Output safety limiter，預設關閉）：輸出 8 V 以下完全不動，
  8 V 以上柔和壓縮，最大不超過 10 V，避免現場硬爆音。LED 量的是限幅**之前**的訊號，
  所以開著限幅器時紅燈仍會提醒你訊號太大；限幅器開啟時立方體右上會顯示 `LIM`。
- **喇叭測試**：TEST 開關會把 1 kHz 正弦（LFE 為 80 Hz）依序輪流送到目前輸出配置的每個聲道（每 1.5 秒），
  面板顯示目前聲道名稱；TEST 開關開關測試，AUTO 開關決定自動輪播或停在 TEST CH 選的聲道；TEST CH 是按鈕，點一下跳下一個聲道，右鍵從清單選（只數目前有接的聲道）。每次只有一個聲道有聲音、一顆燈亮。
  現場請先用它確認 H9000 通道對應。
- 16 個輸入尚未實作，擴充點為 `src/Layout714.hpp` 的 `MAX_TRACKS`（需重排面板）。

完整的面板元件說明見 `面板功能一覽.md`。

## ROOM 擴充模組（The Island Room）
獨立的 6 HP 模組，緊貼在 The Island 左邊或右邊就會生效（LINK 燈亮）。
- **WIDTH / DEPTH / HEIGHT**：房間的寬（左牆↔右牆）、深（前牆↔後牆）、高（耳朵高度的喇叭↔天花板喇叭）。
  只有比例會影響聲像。右鍵 Units 可選公尺／公分／英尺／純數字；旋鈕右鍵可輸入含小數的數字；
  點 RATIO 顯示窗可直接輸入比例（例如 `1:2:0.5`）。預設 10 × 10 × 5 = 正立方體。
- **ORBIT**：FIT（繞場貼合房間）／ROUND（真實空間裡的正圓）。
- 面板上有房間的俯視與側視預覽、比例顯示；The Island 的立方體會跟著變成長方體。
- 沒有接擴充模組時，The Island 的計算和原本完全一樣。
- 面板底圖由 `tools/room_panel.py` 產生（`res/TheIslandRoom*.svg`），版面數值在 `src/Layout714.hpp` 的 `room` 命名空間。

## 座標系
房間立方體，邊長 2，中心為聆聽位置：x 左(-)／右(+)，y 後(-)／前(+)，z 下(-)／上(+)，範圍皆為 -1..1。
預設位置為前牆中央、耳朵高度 (0, 1, 0)。
喇叭位置：L/R 在前牆、方位 ±30°；C 在前牆中央；Ls/Rs 在左右牆中央（±90°）；
Lrs/Rrs 在後方兩個角落（±135°）；頂部四支在天花板 (±0.6, ±0.6, 1)。

## 接法（對應表單方式 1）
1. 模組的 **12CH POLY** 輸出 → VCV 的 **Audio-16** 輸入，通道 1–12（選 4 / 8 聲道配置時只會有 4 / 8 個通道）。
2. Audio 裝置選 H9000（USB-C 轉 USB-B），確認取樣率與主辦方一致。
3. 若 Audio 模組的輸入埠不接受 poly 線，改用面板上 12 個單聲道輸出逐一接 Audio 輸入 1–12。
4. 演出前開啟 TEST，逐聲道確認喇叭位置與名稱一致。

## 從舊版升級（轉換舊 patch）
改名後外掛代號與模組代號都換了，舊的 .vcv 打開時 Rack 會找不到模組。用附的小工具轉換即可，旋鈕、接線、設定都會保留：
```
pip3 install zstandard                                   # 第一次使用前安裝一次
python3 tools/convert_patches.py 我的演出.vcv               # 轉換一個檔案
python3 tools/convert_patches.py ~/Documents/Rack2/patches # 轉換整個資料夾（含子資料夾）
```
轉好的檔案另存為「原檔名 (The Island).vcv」，原始檔案不會被修改。舊版的主題設定不沿用，轉換後一律是 Sky，打開後可在右鍵選單改成 Mist、Sand 或 Dark。
**升級時請先把舊版外掛資料夾 `SilenceTouchSpatial` 從 Rack 的 plugins 資料夾移除**，避免兩個版本同時存在。

## 演算法
距離式振幅聲像（DBAP）：每個喇叭增益 g = 1 / (d² + blur²)^(focus/2)，再做能量歸一化（sum g² = 1）。
與標準 VBAP 不同，不需要喇叭三角網格，聲源在喇叭之間移動時沒有跳變，
代價是定位點比 VBAP 稍微模糊，可用 FOCUS 調整。LFE 不參與空間定位，只由每軌 LFE 送出。
